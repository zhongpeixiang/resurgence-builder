# Fieldkit

A static, GitHub Pages-ready equipment database and loadout builder. It is intentionally an original, small-scope interface rather than a copy of any third-party site.

## Run locally

Open `index.html` in a browser, or run `python3 -m http.server 8000` and visit `http://localhost:8000`.

## Test

```bash
npm test
```

## Publish to GitHub Pages

Create a public repository, push this directory to its `main` branch, then enable **Settings → Pages → Deploy from a branch → main / root**. GitHub Pages will serve the site at the repository Pages URL.

Replace the demonstration catalog in `app.js` only with data and assets you have rights to use.
